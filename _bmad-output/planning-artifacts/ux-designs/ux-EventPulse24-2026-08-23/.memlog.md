- (decision) Dark theme spec — True-black OLED primary. Canvas color.surface.paper = #0A0A0B; elevated #131316; subtle #1B1B1F; inset #232328. Ink primary #F2F2F4 (cool near-white, not warm cream — dark-first breaks the editorial-paper metaphor). Ink secondary #C9C9CF; muted #8A8A92; faint #3A3A40. Border subtle rgba(242,242,244,0.08); strong rgba(242,242,244,0.16).
- (decision) Accent — Terracotta kept, glow-lifted for dark. color.accent.terracotta in dark = #FF6A47 (brighter, more saturated than light-mode #C4502B). Single-accent rule unchanged: only today indicator, primary CTA fill, verified source badge, focus ring. No link underlines, no hover, no category stripes.
- (decision) Category stripes on Pulse Card — kept for warm/cool distinction but raised against dark. color.cool.public (alias color.accent.slate) = #6E7E92; color.warm.personal = #C8967A; color.accent.amber (must-know slot 1 warm stripe) = #E89B4A. Conflict indicator color.warn.amber = #D8A86A (filled circle, top-right; never red). All always paired with visible text labels per WCAG 1.4.1.
