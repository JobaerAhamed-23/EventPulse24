The four states

One vocabulary, four states, precedence cancelled > postponed > moved > sold_out. The banner is ink-only in every state; the badge glyph is signal.warn in every state; line-through carries the distinction. The cancelled state is rendered live in the digest above, so only its Detail-Screen line repeats here.

Card shown live in the digest above.
