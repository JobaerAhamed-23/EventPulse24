Geo-IP consent banner — states

First-visit disclosure required by FR-2. Persisted in a session cookie. Also surfaced in Settings → Privacy after signup. Three states: default, confirmed, fallback.

State 1 — Default (first visit)

.geobar

Geo-IP detected a city. User must make an explicit choice. "Don't use my location" suppresses geo-IP and falls back to NYC at MVP. "Use this" persists the city in a session cookie.

● Showing events near Brooklyn, NY. Use a different city?

After Change tap — inline picker appears below the banner:

Specs: Position: top of page, full-width. Height: ~52px. Font: 13px Inter. Color: terracotta dot + ink-secondary text. Three buttons (Change / Use this / Don't use my location) — Use this is the primary. ARIA: role="region" + aria-label="Location consent". Cookie persistence: ep_geo_choice ∈ {city_id, none}. On revisit with cookie, banner suppressed.

State 2 — Confirmed ("Use this" tap)

.geobar.confirmed

Acknowledgment state shown for 2 seconds after Use this, then collapses into a small footer indicator. The city pill moves into the page header.

✓ Using Brooklyn, NY. Change anytime in Settings → Privacy.
Specs: Background tint shifts to subtle success-green (rgba(122,170,122,0.06)). Icon becomes a checkmark. Single "Confirmed" pill replaces "Use this." After 2s, banner collapses to a footer pill: "📍 Brooklyn, NY · Change". Persistent until cookie cleared or user changes city.

State 3 — Fallback ("Don't use my location")

.geobar.fallback

Geo-IP suppressed. Falls back to most-popular city at MVP (NYC). User can still pick a city via Change. Cookie stores ep_geo_choice = none.

● Showing events in New York, NY (default — your location is off). Use a different city?
Specs: Background tint shifts to subtle amber (rgba(232,155,74,0.06)) — neutral, not red. Copy clarifies the fallback is the default (not the user's choice). "Turn on location" replaces "Use this" — offers a re-prompt path. After confirmed in this state, the page renders Pulse Preview in NYC by default.
