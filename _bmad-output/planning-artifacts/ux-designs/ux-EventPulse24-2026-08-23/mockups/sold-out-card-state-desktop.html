Spec reference

FR-53 / FR-54

Badge: inline pill at the top of the title — desaturated amber (not red), color.signal.warn token per Amendment A-15. Tone: factual, not alarming. Save Reminder CTA: removed (not greyed, not "Notify me when available"). Find similar events: surfaced only on sold-out Detail Screen (not on the card) — quietly resolves the user's likely next intent. Notification frequency: one state-change notification per event per day max. Future state changes (e.g., a cancellation) replace, not stack.
