## Summary of discrepancies found

- **No WRONG or STALE verdicts** on any of the explicitly flagged load-bearing claims (Next.js version/LTS/features, React version, pgvector version/Neon fit, pgvector HNSW fixes, Drizzle version/RC status, Better Auth version/takeover, Claude model ID, embedding model, Stripe SDK, shadcn CLI, Tailwind, Vercel duration limits, Railway cron floor) — all checked out against live primary sources.
- **One superlative could not be fully verified**: "Neon is the *only* managed Postgres above the pgvector 0.8.4 line" (item #24) — directionally supported (RDS/Aurora appear to lag), but Supabase's exact current pgvector version was not pinned down conclusively. Recommend a direct check of Supabase's extensions dashboard/docs before relying on the word "only."
- **One figure is a judgment call dressed as a fact**: the "$0.50/MAU blended ceiling" (item #16) rests on real, verified per-token rates and real discount mechanics, but no source ties those rates to a MAU-based ceiling — that arithmetic depends on assumed usage volume per user, which isn't stated in the spine. Not wrong, but not independently verifiable as written; should be shown as a worked calculation with its assumptions, not asserted as a plain fact.
- **One secondary/aggregator source actively contradicted a primary source** during this review: a blog aggregator claimed Sonnet 5 pricing rose to $3/$15 on Sept 1, 2026, while Anthropic's own live pricing page states that increase was cancelled and $2/$10 is now permanent. The primary source was trusted. This is exactly the failure mode the spine's author avoided by (per the doc's own header) verifying against live sources on 2026-09-04 — good practice, reconfirmed here.
- All other checked figures (Next.js/React versions, pgvector versions and fixes, Stripe/Drizzle/Prisma npm states, Vercel/Railway limits, tokenizer note, AWS benchmark figures, starter-template staleness) were confirmed as stated.
